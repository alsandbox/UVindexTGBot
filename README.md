The [The Sun is a Deadly Laser](https://t.me/sunuv_bot) Telegram bot provides the current UV index.
- Uses webhooks with ASP.NET Web API, and the initial version uses long polling.
- Deployed on a cloud-based Linux server with Docker and ngrok.
- Uses System.Text.Json to deserialize JSON from the API.
